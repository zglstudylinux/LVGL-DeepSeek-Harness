# 03 · 移植指南 —— 单片机（MCU）

> 模板参考：`ports/stm32f4xx/`（含拷贝清单与 port.c 骨架）。

## 核心思路

MCU 项目依赖厂商 HAL 与 IDE 工程，通常**不走本仓库顶层 CMake**，
而是「拷贝清单」方式把源码加入 Keil / IAR / STM32CubeIDE 工程。
移植的唯一工作 = 实现 `ports/<芯片>/src/port.c` 的三个函数。

## 拷贝清单

| 源码 | 说明 |
|------|------|
| `lvgl/src/` | LVGL 库核心（加入工程源文件） |
| `lvgl/include/` | LVGL 头文件（加入 include 路径） |
| `apps/<应用>/` | 你的 UI 源码（含 `apps/<应用>/lv_conf.h`） |
| `shared/` | 平台接口 + 应用框架 + utils（加入 include 路径） |
| `ports/<芯片>/src/port.c` | 平台实现（补全 LCD/触摸/tick） |

## 实现 port.c 三函数

```c
static void port_init_impl(void) {
    // 1) 显示：lv_display_create(W, H) + lv_display_set_flush_cb(disp, my_flush)
    //    或直接用内置驱动 lv_st7789 / lv_ili9341 / lv_lcd_generic_mipi
    // 2) 触摸：lv_indev_create() + 读取坐标填充 + lv_indev_set_read_cb

}
static uint32_t port_tick_ms_impl(void) { return HAL_GetTick(); }
static void     port_delay_ms_impl(uint32_t ms) {

}
```

## 配置宏（IDE 工程）

- `LV_CONF_INCLUDE_SIMPLE`（把 `apps/<应用>/lv_conf.h` 所在目录加入 include 路径）。
- 用 RTOS 时设 `LV_USE_OS`（lv_conf.h 内），并让 `port_delay_ms` 走任务让出。
- 按需在 `apps/<应用>/lv_conf.h` 里裁剪：关 demos/examples、调 `LV_MEM_SIZE`、选色深 `LV_COLOR_DEPTH`。

## 主循环照搬

`apps/<应用>/src/main.c` 的骨架可直接搬进 RTOS 任务或裸机 `while(1)`：

```c
lv_init();
port_get()->init();
app_init();
while (1) { lv_timer_handler(); port_get()->delay_ms(5); }
```

**应用与业务代码（apps/*、model/service）一行不改**，这正是架构的解耦红利。

## 注意事项

- include 一律用相对路径，别写绝对路径，拷贝清单才能到处可用。
- 若 flash 紧张，可在 lv_conf.h 关闭不需要的控件/特性以减小体积。
- 触摸坐标记得换算到 LVGL 的显示分辨率（`lv_display_set_resolution`）。
